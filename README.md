# Точка переходу

Лендінг закритої україномовної спільноти для транс-людей.
Сайт: [transitionpoint.party](https://transitionpoint.party)

Дизайн і розробка — **Painted Fox Studio**.

## Як це влаштовано

Сторінка складається з п'яти станів, між якими людина переходить кнопками, скролом, свайпами або клавішами ↑ ↓:

```
hero ⇄ світлий екран ⇄ вода ⇄ світанок
                         ⇅
                    бульбашки з питаннями
```

Увесь фон малює один фрагментний шейдер на WebGL 1: куля з акреційним диском, тепла кімната, вода з променями, мильні бульбашки, розсипання тексту на частинки, світанок і потьоки води. Тексти, кнопки й фото — звичайний HTML і CSS поверх нього, тому вони доступні для скрінрідерів і пошуку.

## Структура

```
index.html          розмітка всіх екранів (одна для всіх пристроїв)
404.html            сторінка «не знайдено»
css/style.css       стилі, розбиті на пронумеровані розділи
css/not-found.css   стилі сторінки 404
js/main.js          точка входу, швидкий вихід
js/app.js           машина станів: переходи, фокус, inert, оновлення кадру
js/renderer.js      WebGL: ініціалізація, ресайз, втрата контексту
js/shaders.js       GLSL-шейдери
js/input.js         колесо, тачпад, свайпи й клавіатура → «наміри»
js/bubbles.js       розкладка й анімація бульбашок з питаннями
js/rasterize.js     малює видимий текст у canvas для ефекту розсипання
js/tween.js         анімаційні примітиви
js/config.js        усі тривалості, пороги й налаштування в одному місці
fonts/              Alegreya та Alegreya Sans (SIL OFL), латиниця й кирилиця
og-image.jpg        прев'ю для Telegram і соцмереж
```

## Запуск локально

Скрипти підключені як ES-модулі, тому `index.html` не відкриється подвійним кліком. Потрібен будь-який локальний сервер у папці проєкту, наприклад:

```bash
python -m http.server 8000
```

і відкрити <http://localhost:8000>. Або розширення Live Server у VS Code.

## Публікація

Сайт статичний, збірка не потрібна.

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Файл `CNAME` вже містить домен `transitionpoint.party`.
- **Cloudflare Pages:** підключити репозиторій, команду збірки лишити порожньою, вихідна папка — корінь.

## Що де змінювати

- **Тексти, фото, посилання на Telegram** — у `index.html`. Усі тексти погоджуються з Ілоною.
- **Тривалості анімацій, чутливість жестів, розташування бульбашок** — у `js/config.js`.
- **Кольори й розміри** — змінні на початку `css/style.css`.
- **Адреса швидкого виходу** — `QUICK_EXIT_URL` у `js/config.js` і `href` посилання «Швидкий вихід» в `index.html`.

## Приватність і безпека

- Жодних трекерів, аналітики, cookies чи зовнішніх запитів: шрифти й усі ресурси лежать у репозиторії.
- Content-Security-Policy дозволяє завантажувати лише власні файли сайту.
- `referrer: no-referrer`, тож переходи з сайту не розкривають, звідки прийшла людина.
- Швидкий вихід (кнопка або Esc) замінює сторінку в історії через `location.replace`, тому «Назад» на неї не повертає.

## Доступність

- На кожному кроці доступний лише поточний екран: решта отримує `inert`, а фокус переходить на заголовок нового екрана.
- Розміри тексту реагують на масштабування браузера й системний розмір шрифту. Якщо збільшений текст не вміщається, екран можна прокрутити.
- Повністю працює з клавіатури: Tab, Enter, ↑ ↓, Esc.
- При `prefers-reduced-motion` фонові рухи зупиняються, а переходи стають короткими.
- Без WebGL сайт показує прості кольорові фони й лишається робочим, а без JavaScript — повідомлення з посиланням на Telegram.
